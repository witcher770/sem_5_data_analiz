# sem_5_data_analiz
репозиторий для лаб по предмету введение в анализ данных

Отвечаю по каждому вопросу:

---

**Почему random_state=42?**

42 — это широко принятое в ML-сообществе соглашение, восходящее к книге "Автостопом по галактике" (ответ на главный вопрос жизни). На практике конкретное число не имеет значения — важно что оно фиксировано. Можно сказать так: *"random_state=42 выбран для воспроизводимости эксперимента — при повторном запуске тетради разбивка и результаты будут идентичны. Значение 42 является стандартным в учебных и исследовательских работах по ML."*

---

**Почему разбивка 75/25 (test_size=0.25)?**

В примере именно 75% обучение / 25% валидация. Обоснование: *"Разбивка 75/25 выбрана как классический компромисс: обучающая выборка достаточно велика для качественного обучения модели, а валидационная (25%) достаточна для статистически надёжной оценки качества. При более мелких датасетах уменьшение обучающей части ниже 70% приводит к нестабильности модели. Использован параметр stratify для сохранения пропорций классов в обеих выборках, что критично при возможном дисбалансе классов."*

---

**Почему выбраны именно Logistic Regression и MLP?**

Логистическая регрессия:
*"Логистическая регрессия выбрана как базовая (baseline) модель: она интерпретируема, быстро обучается и хорошо работает на линейно разделимых данных. Её веса показывают, какие признаки наиболее значимы для классификации. Если нейронная сеть не даёт существенного прироста качества по сравнению с логрегрессией — это сигнал, что задача линейно разделима и усложнение модели нецелесообразно."*

MLP (многослойный перцептрон):
*"MLPClassifier выбран как алгоритм глубокого обучения, поскольку задача классификации по числовым и категориальным признакам не имеет пространственной или последовательной структуры — значит архитектуры CNN и RNN избыточны. Полносвязная нейросеть способна аппроксимировать нелинейные зависимости между признаками, которые логистическая регрессия не улавливает. Два скрытых слоя (64→32) позволяют модели выучить иерархические признаки без риска переобучения на табличных данных среднего объёма."*
